01 / FEATURES

学生に必要なものを、ひとつの画面に。

Moodleの散らばった画面を、一貫したワークスペースへ統合します。

⌂

ダッシュボード

締切・進捗・未読を一目で。今日やるべきことから始められます。

▤

コースと教材

教材、活動完了、標準活動を /activities/[cmid] の共通ワークスペースへ統合。

⇪

課題提出

ファイルとオンラインテキストの提出を、迷わない導線で。

◷

カレンダー

締切と予定を時間割とともに。ICS書き出しにも対応。

✉

メッセージと通知

会話一覧、メッセージ送信、通知の既読化までシームレスに。

★

成績・バッジ・学習プラン

成績、参加者、プロフィール、プライベートファイルもまとめて。

⎙

端末内PDFツール

PDFの結合や編集をブラウザ内で完結。ファイルは外へ出ません。

⌘

コマンドパレット

キーボードショートカットで、どの画面へも一瞬で移動。

02 / SECURITY

速さのために、安全を妥協しない。

トークンは暗号化されたHttpOnly Cookieから外へ出さず、Moodle由来のHTMLとファイルはサーバー境界で検証します。

  • 暗号化 HttpOnly Cookie Moodleトークンはブラウザのスクリプトから一切読めません。
  • サーバー境界でのサニタイズ Moodle由来のHTMLは型付き画面モデルへ変換してから描画します。
  • 能力マニフェスト 関数一覧はSHA-256と小さなマニフェストだけを保持。権限のない機能は明示的に無効化。
  • 任意URLプロキシなし 1デプロイは1つの信頼済みMoodleにのみ接続。同一オリジンの検証済みURLだけを開きます。

03 / ARCHITECTURE

Moodleはそのまま。体験だけを置き換える。

Moodle本体への改修やプラグインは不要。BFFが公式APIとブラウザの間に立ちます。

CLIENT ブラウザ React 19 / Next.js UI
HttpOnly Cookie
BFF next-moodle 検証・サニタイズ・型付け
Web Service API
SOURCE OF TRUTH Moodle moodle_mobile_app

04 / GET STARTED

3ステップで起動。

.env.local に MOODLE_BASE_URL と SESSION_PASSWORD を設定するだけ。

zsh — next-moodle

# 1. クローン
$ git clone https://github.com/Louis-kohaku/next-moodle.git
$ cd next-moodle

# 2. 秘密鍵を生成して .env.local へ
$ openssl rand -hex 48

# 3. 起動
$ bun install
$ bun run dev
